# TAR-69 — Cambiar la navegación en drawer por un bottomNavigation

- estado: en curso
- version: v1.3.0
- tipo: feat

## Problema

Cambiar el sistema de navegación en formato drawer por uno clásico y reestructurar las pantallas de navegación y botones.

## Decisión

Las pantallas principales serán Home, Library, Registry, Stats cuando esté disponible la funcionalidad. A parte botones auxiliares como el gestor de contenidos, ajustes, about, etc se redistriburirán en las topBar de cada pantalla.
