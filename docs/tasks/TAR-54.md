# TAR-54 — Sistema favoritos + estantería Home

- estado: hecho
- version: v1.3.0
- tipo: feat

## Problema

## Decisión

Hacer un sistema de favoritos donde los usuarios puedan marcar sus libros preferidos y tener un estante en home con estos libros. El ordenado manual se queda fuera del alcance de esta tarea.

## Durante el desarrollo

Se tomó la decisión de dejar el sistema de favoritos únicamente para la ficha de detalles de los libros mediante un botón. Además para un mejorado visual se mejoró la interfaz de esta pantalla. Se añadió un indicativo en la biblioteca para los libros marcados como favoritos y se añadió una opción de filtrado para estos.

## Resolución

Todo se ha desarrolado conforme se ha explicado en la sección anterior y queda pendiente el rediseño de la pantalla home para otra tarea posterior.
