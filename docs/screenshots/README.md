# Screenshots

Portrait PNGs for the README (device or emulator, ~1080×2340). Each file maps to a titled section in [README.md](../../README.md) / [README.es.md](../../README.es.md).

| File | Section |
|------|---------|
| `home.png` | Home |
| `library.png` | Library |
| `reader.png` | Reader |
| `registry.png` | Registry |
| `physical.png` | Physical book *(optional)* |

When a file is in this folder, uncomment the matching `<p align="center"><img …></p>` block in both READMEs and delete the “Add `docs/screenshots/…`” line.
